# Credit-card-application-approval
This project is based on credit card applications approval or rejection . It is a supervised classification model .
This project got extensive data cleaning .  missing and null values imputing has been done and a lot of  data visualization is there to get meaningful insights .
I have run this model with 7 different ML algorithms along with hyperparameter tuning in few algorithms .
